Расширение для директолога!

Практика30 октября 2026

Расширение для клонирования ТМК переработано. Теперь оно не просто клонирует ТМК, а ещё:

  1. Статусы обучения стратегий теперь видны без входа в кампании, в том числе в МК и ТМК.
  2. Массовые чекбоксы для всех рекламных кампаний, включая МК и ТМК. Можно отметить кампании галочками и сразу запустить, остановить или архивировать.
  3. Чистка площадок по статистике. Задаёте условие «расход от X и 0 конверсий», отмечаете подходящие площадки и минусуете их без Мастера отчётов.

Установить расширение из Chrome Web Store.

Предложения по доработке можно отправить разработчику.
