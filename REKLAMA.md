# Страница для рекламодателей

Адрес после публикации: https://romanulin.ru/reklama

Страница реализована в существующем статическом проекте. Шапка, футер, меню, кнопки и FAQ используют общие ресурсы сайта. Пункт «Реклама» в меню не добавлен. Для статистики нужен PHP 8.1+ с cURL на хостинге. Без подключённого TGStat страница работает и показывает нейтральное сообщение вместо чисел.

## Подключение TGStat на Timeweb

1. Войдите или зарегистрируйтесь в TGStat. Откройте личный кабинет и раздел API. Получите персональный API Token по [официальной инструкции](https://api.tgstat.ru/docs/ru/start/token.html). Проверьте, что вашему аккаунту доступен метод `channels/stat` API Stat и есть квота. Условия доступа смотрите в [TGStat API](https://tgstat.ru/api/stat).
2. В панели Timeweb найдите каталог сайта romanulin.ru и его `public_html`. Точный путь зависит от аккаунта. Убедитесь, что для сайта доступен PHP 8.1 или новее и расширение cURL. Менять режим PHP специально для этой страницы не требуется.
3. **Рядом с `public_html`, а не внутри него**, создайте папку `.romanulin-private`. Например, если сайт находится в `/home/ACCOUNT/romanulin/public_html`, закрытая папка должна быть `/home/ACCOUNT/romanulin/.romanulin-private`.
4. Скопируйте содержимое `tgstat-config.example.php` в файл `.romanulin-private/tgstat.php`. В закрытом файле замените `YOUR_TGSTAT_TOKEN` на свой токен. Не меняйте шаблон в проекте и не отправляйте токен в чат. Каталог и файл должны быть доступны PHP: обычно достаточно прав 700 на каталог и 600 на файл, если владелец совпадает с пользователем PHP.
5. Оставьте `TGSTAT_CACHE_TTL` равным `86400`. PHP создаст внутри закрытой папки каталог `cache`; ему нужна возможность записи туда. Если автоматическое создание запрещено, создайте `cache` вручную с правами для PHP.
6. После отдельного решения о публикации загрузите публичные файлы страницы и обе `.htaccess`. Закрытый файл с токеном создаётся только на сервере. Документация, пример конфигурации, тесты и приватные файлы исключены из настроенного FTP workflow. Сейчас ничего не опубликовано.
7. Откройте `/reklama` и `/api/tgstat.php`. Успешный ответ содержит шесть числовых полей, `updatedAt` и `stale: false`; токена в ответе нет. На странице появятся цифры и московское время успешного обновления. Повторное открытие должно сохранять эту дату до истечения TTL.

Если цифры не появились: проверьте путь закрытого файла, правильность токена, доступ к API Stat/квоту, cURL, исходящий HTTPS и права на кеш. После неуспешного запроса действует пауза 5 минут. Не включайте вывод технических ошибок в публичном endpoint.

Альтернатива закрытому файлу — серверные переменные окружения `TGSTAT_TOKEN`, `TGSTAT_CACHE_TTL`, `TGSTAT_CACHE_DIR`. Настройка этих переменных зависит от режима PHP. Закрытый файл проще для обычного виртуального хостинга.

## Кеш и частота обновления

- По умолчанию TTL — **86400 секунд (24 часа)**.
- Кеш: `../.romanulin-private/cache/direct-ulin.json` относительно корня сайта (`public_html`). Он содержит только метрики и дату, без токена.
- `direct-ulin.lock` предотвращает одновременные запросы; `direct-ulin-retry.json` ограничивает повторы при ошибках на 300 секунд.
- Обновление происходит по первому посещению после окончания TTL, а не по расписанию. Без посетителей запросов к TGStat нет.
- Чтобы изменить частоту, измените `TGSTAT_CACHE_TTL` в **закрытом серверном файле**, например на `3600` для часа. Учитывайте квоту TGStat. Сборка сайта не нужна.
- При ошибке API или сети сохраняются последние успешные цифры и исходная дата обновления. Если кеша ещё нет, показываются прочерки и нейтральное сообщение. Нули не подставляются вместо неизвестных значений.
- По желанию задайте абсолютный `TGSTAT_CACHE_DIR`; каталог должен существовать вне web root. Публичные каталоги и символьные ссылки внутрь web root отвергаются.

## Контент и обслуживание

- Тексты и SEO: `reklama/index.html`; стили: `css/reklama.css`.
- Аватарка — копия существующего оригинала `img/personal/telegram-avatar-blue.jpg`, без изменения фотографии. Web-копия `telegram-avatar-blue-web.jpg` весит около 214 КиБ вместо 804 КиБ; разрешение осталось 1080×1080. Оригинал не изменён.
- Временный блок имеет `data-campaign-until="2027-01-01T00:00:00+03:00"`. С начала 2027 года он скрывается, включая открытую через полночь вкладку. Сам компонент остаётся в исходнике. Дата вычисляется в браузере; его системные часы должны быть корректными.
- Примеры размещений: `data/reklama-examples.json`, сейчас `[]`. Для появления блока добавляйте только реальные объекты с полями `title`, `description`, `url`. Ссылки допускаются только на публикации `https://t.me/direct_ulin/НОМЕР`. Никаких рекламодателей или результатов по умолчанию нет.
- Точный адрес `/reklama` обслуживается корневой `.htaccess` и `reklama/.htaccess`. Варианты со слешем и `index.html` перенаправляются на него. Настройки остальных директорий не изменены.
- Для локального просмотра нужен HTTP-сервер с PHP. Открытие HTML через `file://` не заменяет серверную часть TGStat. GitHub Pages не исполняет PHP: на нём статистика останется недоступной.

## Проверки

Выполнены `npm run build`, `npm run check`, `npm test`, `node scripts/test-reklama.cjs`, `php scripts/test-tgstat.php`, проверка PHP-синтаксиса. Тесты используют отдельный временный каталог и условные данные, которые не попадают на страницу.

Проверены: отсутствие повторных upstream-запросов при свежем кеше, обновление после TTL, сохранение данных/даты при ошибке, пауза повторов, блокировка одновременного обновления, отсутствие токена, запрет публичного кеша, граница окончания акции по Москве, форматирование чисел и даты, один H1 и JSON-LD. На локальном Apache проверены `/reklama` (200), перенаправления (301 → 200), запрет доступа к шаблону конфигурации (403), главная страница (200).

В браузере проверены desktop, tablet и mobile, включая ширину 320 px, загрузка аватарки, отсутствие горизонтального переполнения, FAQ и консоль. Исходники существующих страниц, общие CSS/JS и оригинальные изображения не менялись. Существующие тесты подтверждают неизменность статей.

**Живое подключение TGStat не проверено: персональный токен не предоставлялся.** До его настройки сервер честно возвращает отсутствие статистики. Сайт не закоммичен, не отправлен в GitHub и не загружен на Timeweb.
